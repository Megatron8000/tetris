# Панельки — Android Tetris

Android-проект на Kotlin: классический Тетрис с плоскими фронтальными пиксельными окнами советских домов на фоне 8-битного звёздного неба и облаков.

## Сборка APK

GitHub Actions собирает debug APK при push в `main` и вручную через вкладку Actions. Готовый APK доступен в артефактах workflow `Android APK`.

## Технологии

- Kotlin, Android SDK, Android Canvas
- Gradle Wrapper
- Оффлайн-игровая механика и локальное сохранение рекорда
